# Дерево черт классов PF2e

Интерактивные деревья классовых черт Pathfinder 2e Remaster в духе пассивного дерева Path of Exile 2.
Описания, уровни, дескрипторы и критерии подтягиваются с pf2.ru (поборник) и Archives of Nethys (волшебник, на английском).

Классы переключаются вкладками над левой панелью (в адресе — `?class=…`):

- **Поборник** — все черты 1–20 уровня ([pf2.ru](https://pf2.ru/classes/champion?tab=feats));
- **Волшебник** — все черты 1–20 уровня на английском ([Archives of Nethys](https://2e.aonprd.com/Feats.aspx?Traits=166)).
  Сверху — школа магии (Arcane School) и диссертация (Arcane Thesis). School of Unified Magical Theory даёт ячейку
  черты 1 уровня, Improved Familiar Attunement — черту Familiar.

У каждого класса своя сохранённая сборка.

## Запуск

Откройте `index.html` в браузере. Можно и через локальный сервер:

```
node tools/serve.mjs
```

и откройте http://localhost:5173.

## Управление

- сверху — карточки выбора: освящение, призвание, заклинание преданности, благословение верного;
  если черте нужна такая карточка, у узла слева сверху маленький медальон (золотой — условие выполнено)
- **Наведение** на узел — короткая подсказка: уровень, статус или причина запрета, строка описания
- **ЛКМ** по узлу (или `i`) — панель справа с полным описанием и ссылкой на источник (на узком экране — снизу)
- **Двойной клик** или **Enter** по узлу, **ЛКМ** по карточке слева — взять / снять (зависимые узлы снимаются автоматически)
- наведение или Tab на узел — подсказка: описание, критерии, стоимость, кнопка «Взять»;
  цепочка требований подсвечивается, остальное приглушается; Enter — взять / снять, Esc — закрыть
- перетаскивание — перемещение, колесо / щипок — масштаб, ⤢ или `0` — вписать дерево в экран
- внизу слева — уровень, потраченные ячейки, «Отменить» (Ctrl+Z, 50 шагов) и «Сброс»
- верхнюю панель выбора можно свернуть (▴); у волшебника справа — описание выбранной школы и диссертации
- состояния узлов: золото со свечением — взято, светлая рамка — можно взять, замок — закрыто;
  легенда — в правом нижнем углу

Учитываются уровень персонажа, ячейки классовых черт (1 ур. и каждый чётный),
освящение → призвание, выбранное заклинание преданности, благословение верного
(второе — через черту «Второе благословление»). Сборка сохраняется в браузере,
кнопка «Ссылка на сборку» даёт ссылку, которой можно поделиться.

## Обновление данных

```
node tools/fetch-pf2.mjs          # поборник: скачать (с кешем в data/cache)
node tools/fetch-pf2.mjs --force  # перекачать всё заново
node tools/build-graph.mjs        # пересобрать поборника без скачивания
node tools/fetch-wizard-aon.mjs   # волшебник с AoN → data/wizard/source/aon.json и сборка
node tools/fetch-wizard-pf2ru.mjs # перевод pf2.ru для волшебника → data/wizard/source/pf2ru.json
node tools/build-wizard.mjs       # пересобрать волшебника (граф и все переводы) без скачивания
node tools/check-data.mjs         # проверить данные: схемы, ссылки, иконки, тексты
```

### Как хранятся данные

У каждого класса своя папка `data/<класс>/`:

| папка | что там | кто пишет |
|---|---|---|
| `source/` | скачанное с сайтов как есть (`pf2ru.json`, `aon.json`) | загрузчики `fetch-*.mjs` — руками не править |
| `manual/` | всё, что задано руками: `rules.json` (темы, исправления критериев, группы выбора), `images.json` (иконки), `labels.json` (переводы, подписи корня, групп и тем), переводы, набранные вручную (`doc-yura.json`) | вы |
| `build/` | то, что читает сайт: `graph.js` — узлы, связи и координаты без текстов; `text-<перевод>.js` — тексты узлов | сборщики `build-*.mjs` |

Ручные файлы описаны схемами в `data/schema/` (поле `$schema` в начале файла — VS Code подсказывает поля и
подчёркивает ошибки). `node tools/check-data.mjs` проверяет схемы и ссылки: темы и группы есть в графе,
черты из правил есть в скачанных данных, файлы иконок существуют, у каждого узла есть текст в каждом переводе.
Сборка пишет `.js`, а не `.json`, чтобы сайт открывался без сервера (двойным щелчком по `index.html`).

Порядок правки: поменять `manual/*.json` → `node tools/build-graph.mjs` или `build-wizard.mjs` →
`node tools/check-data.mjs`.

- `tools/pf2-common.mjs` — общие функции: загрузка с кешем, разбор таблиц, вьюбоксов и карточек подклассов.
- `tools/fetch-wizard-aon.mjs` — волшебник с Archives of Nethys: открытый поисковый индекс сайта
  (`elasticsearch.aonprd.com/aon`, без ключей), только версии Remaster; разметку AoN переводит в HTML.
- `tools/build-wizard.mjs` — граф волшебника и тексты всех переводов (`tools/build-wizard-i18n.mjs`).
- `tools/class-build.mjs` — общее для сборщиков: где лежат данные, чтение и запись `source/`, `manual/`, `build/`.
- **Переводы волшебника** (переключатель «Перевод: AoN · pf2.ru · Док и Юра» в шапке). Граф один — меняется
  только текст узлов. `data/wizard/manual/doc-yura.json` — перевод Дока и Юры (pf2e.ru), переписанный вручную со
  скриншотов модуля перевода Foundry VTT (`images/foundryDocTranslation/`, в git не входят): названия,
  описания, критерии, триггеры, требования; у школ и диссертаций — только названия. Чего нет в переводе,
  берётся из другого русского перевода или из AoN, с пометкой в карточке. В карточке видно, как узел
  называется в других переводах; поиск ищет по всем.

- `tools/fetch-pf2.mjs` — скачивает страницу класса и описания каждой черты (`/viewbox/...`), сохраняет `data/champion/source/pf2ru.json`.
- `tools/build-graph.mjs` — превращает сырые данные в `data/champion/build/`. Здесь — разбор текстовых
  критериев («благословенный щит», «аура поборника»…); ручные данные (какие призвания требуют освящения,
  исправления критериев `overrides`, иконки) — в `data/champion/manual/`.

- `tools/tree-layout.mjs` — **в ветке `tree-trunk` используется он**: дерево от корня без колец.
  Корень → темы (Призвание, Преданность, Благословение, Ауры, Щит, Скакун, Вера и клятвы, Освящение, Бой) →
  ствол темы, черты по сторонам по возрастанию уровня. Строится за доли секунды, без оптимизации.
  Темы черт задаются в `themes` / `themeByName` в `data/<класс>/manual/rules.json`.
- `tools/layout.mjs` — прежняя кольцевая раскладка (в этой ветке не используется) (вызывается сборщиком, занимает 2–5 мин). Узел всегда лежит на кольце своего уровня
  и в одном из `GRID` (40) угловых слотов — поэтому соседи на кольце стоят на одинаковом шаге, а цепочки
  выстраиваются почти прямыми лучами (штраф за излом сильнее 17°). Слот подбирается оптимизацией так, чтобы узлы не накладывались, рёбра не пересекались и не проходили
  через чужие узлы, а подписи (сторону — снизу/сверху/слева/справа — оптимизатор выбирает сам) не задевались
  ни связями, ни другими узлами и подписями. Итог печатается в консоль:
  `пересечений 0, рёбер через узлы 0, наложений 0, задетых подписей 0`.
  Расстояния и размеры — в `GEOMETRY` (`R_STEP` — шаг между кольцами уровней, `SIZE` — размеры узлов).
  Порядок тематических секторов задаётся `ROOT_ORDER`, место черт без критериев — `LAYOUT_ANCHOR`.

Если сайт добавит новую черту, скрипт напишет предупреждение (нет картинки / критерии не распознаны) —
допишите правило в `data/<класс>/manual/` (иконку — в `images.json`, критерии — в `overrides` в `rules.json`).

## Структура

```
index.html, style.css, app.js   приложение
data/<класс>/source/          скачанные данные (pf2.ru / AoN)
data/<класс>/manual/          ручные правила, иконки, подписи, переводы
data/<класс>/build/           собранный граф (graph.js) и тексты переводов (text-<перевод>.js)
data/schema/                  JSON-схемы ручных файлов
fonts/                          шрифты Oswald и Inter (OFL)
images/                         иконки узлов
tools/                          загрузчик, сборщик графа, локальный сервер
legacy/                         предыдущая версия приложения
```
