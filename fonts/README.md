# Шрифты

| Файл | Шрифт | Где используется |
|---|---|---|
| `oswald-*.woff2` | Oswald 600 | заголовки, секции (uppercase) |
| `inter-*.woff2` | Inter 400–700 (переменный) | весь текст |

Наборы символов: latin, latin-ext, cyrillic, cyrillic-ext. Подключаются через `fonts/fonts.css`
(его подключает `index.html`), сеть для них не нужна.

Источник — Google Fonts (fonts.gstatic.com). Оба шрифта распространяются по лицензии
SIL Open Font License 1.1: https://openfontlicense.org — их можно использовать и распространять
вместе с проектом, в том числе в коммерческих целях; продавать сами шрифты отдельно нельзя.
